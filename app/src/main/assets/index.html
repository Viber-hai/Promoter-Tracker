What’s new

Updates in this version of Promoter Tracker.

Latest update
  • Fingerprint app lock with a six-digit backup PIN and automatic locking after inactivity.
  • Manual and scheduled backups are encrypted with AES-256-GCM; same-phone restore uses Android Keystore automatically.
  • Optional recovery password lets you restore encrypted backups on a new phone.

Earlier improvements
  • Editable monthly targets in Settings.
  • Model management moved out of the main product list.
  • Automatic and manual backup, restore, and backup location settings.
