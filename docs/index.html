Android sales companion

Keep your sales targets and incentives in view.

Promoter Tracker is an Android app for recording product sales, following category targets and calculating incentive progress in one place.

View project on GitHub Read the privacy policy

Built for everyday tracking

Sales by category

Record quantities for handset and tablet products, plus audio and wearable products.

Targets and progress

Set category targets and see achievement progress alongside an overall score.

Incentive calculations

Track per-unit incentives and see estimated totals based on recorded sales and the app's scoring rules.

Privacy and app lock

Use the app's available PIN and Android biometric security options to help protect access to incentive information.

Backup and restore

Create local backups and, in the Android app, optionally connect Google Drive for encrypted backup and restore.

Designed for mobile

A compact interface designed for quick updates on an Android phone.

Project status: This site provides information about the project. It does not host or install the Android app. Check the GitHub repository for the current source code, build instructions and available releases.
